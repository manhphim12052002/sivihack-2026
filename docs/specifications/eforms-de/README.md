# eforms-DE Specification 2.2.0 (from 2026-09-10) 

This project contains the concrete semantic model of eForms-DE (the German tailoring of eForms). It is based on the Simple Semantic Data Model in XML (SeMoX) approach.

The distribution contains the structured eforms-DE model data as well as the specification rendered as PDF in 2.2.0 (from 2026-09-10).


It also contains the original source of the specification changelog (chapter 10 "Änderungshistorie"): `specification-changelog.md`. It documents all semantically relevant changes. 

## Online Resources 

- The official versions of the eForms-DE Standard are published at [XEinkauf web site](https://xeinkauf.de/eforms-de/).
  - Please visit this site for reference.

- Detailed structured date on the semantic specification can be found in [eforms-model-data](https://projekte.kosit.org/eforms/eforms-ts/-/tree/master/src/main/model)
